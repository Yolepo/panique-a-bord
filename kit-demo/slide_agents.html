Piste 01 • Git & Isolation
Vraies Pull Requests par Agent
Utiliser les workspaces partagés (git worktrees) pour que Cambouis et Gouache travaillent sur des branches séparées et ouvrent de vraies PR revues par Pinailleur.
Piste 02 • Automatisation
Pilotage Événementiel (Webhooks / Cron)
Ne même plus taper les prompts dans l'IDE : dès qu'une Issue est créée ou qu'une alerte Sentry remonte en prod, l'équipe d'agents prépare un correctif en tâche de fond.
Piste 03 • Mémoire Collective
Amélioration Continue des Skills
Quand Videur découvre une faille, un agent met à jour automatiquement les règles dans .agents/skills/ pour vacciner toute l'équipe sur les prochains développements.
Piste 04 • Gouvernance
Human-in-the-Loop sur les Décisions Clés
Laisser les agents autonomes sur le code, les tests et la doc, mais bloquer le merge final ou les changements d'architecture sur l'approbation d'un Tech Lead humain.
Piste 05 • Nouveaux Rôles
Élargir le Comité d'Agents
Ajouter un agent FinOps (suivi du coût des tokens pro vs flash), un agent DBA (migrations SQL), ou un agent Accessibilité (audit RGAA / WCAG).
Piste 06 • Écosystème Entreprise
Connexion MCP aux Outils Internes
Brancher le même comité sur Jira, GitLab, SonarQube, Datadog ou Slack via des serveurs MCP pour s'intégrer aux workflows existants de l'entreprise.
